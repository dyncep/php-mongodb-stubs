# MongoDB PHP Extension Stubs

MongoDB PHP extension stubs for IDE autocompletion and type hinting.

## Installation

```bash
composer require --dev dyncep/php-mongodb-stubs
```

## Usage

Once installed, your IDE will automatically use these stubs for MongoDB extension autocompletion and type hinting.

## Updating Stubs

To update the stubs to the latest version from PHPStorm:

```bash
./update-stubs.sh
```

## What are stubs?

Stubs are PHP files that contain function and class signatures without implementation. They provide IDEs with the information needed for autocompletion, type checking, and documentation popups for the MongoDB PHP extension.
